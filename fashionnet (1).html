Project Overview

What This Project Does

A complete deep learning pipeline that classifies clothing images using a 3-block CNN built with TensorFlow and Keras.

The Problem
10
Fashion categories classified from 28×28 grayscale images — T-shirts to ankle boots.
The Approach
CNN
Three convolutional blocks extract spatial features, then dense layers make the final prediction.
The Result
89.19%
Test accuracy in 5 epochs using Adam optimizer and sparse categorical cross-entropy.

Source Code

Implementation

Three stages from project_code_fnl.py — build, train, evaluate.

project_code_fnl.py · CNN Model
# Step 3: Build CNN Model (Improved)
model = Sequential([
    # Block 1 — 32 filters, detects edges & textures
    Conv2D(32, (3,3), activation='relu', input_shape=(28,28,1)),
    MaxPooling2D((2,2)),              # 13×13×32

    # Block 2 — 64 filters, detects shapes & patterns
    Conv2D(64, (3,3), activation='relu'),
    MaxPooling2D((2,2)),              # 5×5×64

    # Block 3 — 64 filters, high-level classification
    Conv2D(64, (3,3), activation='relu'),  # 3×3×64

    Flatten(),
    Dense(64, activation='relu'),
    Dense(10, activation='softmax')  # 10 class probs
])
# Total params: 93,322 (364.54 KB)

model.compile(optimizer='adam',
              loss='sparse_categorical_crossentropy',
              metrics=['accuracy'])
