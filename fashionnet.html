Project Overview

What This Project Does

A deep learning pipeline that takes grayscale fashion images and identifies the correct clothing category using a 3-block convolutional architecture.

The Problem
10
Fashion categories to classify — from T-shirts to ankle boots — using only 28×28 pixel grayscale images as input.
The Approach
CNN
Three convolutional blocks with max-pooling extract spatial features, followed by dense layers for final classification.
The Result
91.3%
Test accuracy achieved in just 5 training epochs using the Adam optimizer and sparse categorical cross-entropy loss.
Dataset

Fashion MNIST

A drop-in replacement for classic MNIST — 60,000 training and 10,000 test images of fashion items at 28×28 pixels in grayscale, split across 10 clothing categories.

Source Code

Implementation Walkthrough

The pipeline is split into three stages: building the model, training it, and evaluating predictions on unseen data.

project_code_fnl.py · CNN Model
# Step 3: Build CNN Model
from tensorflow.keras.models import Sequential
from tensorflow.keras.layers import Conv2D, MaxPooling2D, Flatten, Dense

model = Sequential([
    # Block 1: Extract low-level features (edges, textures)
    Conv2D(32, (3,3), activation='relu', input_shape=(28,28,1)),  # 26×26×32
    MaxPooling2D((2,2)),                                       # 13×13×32

    # Block 2: Extract mid-level features (shapes, patterns)
    Conv2D(64, (3,3), activation='relu'),                     # 11×11×64
    MaxPooling2D((2,2)),                                       # 5×5×64

    # Block 3: Extract high-level features (clothing type)
    Conv2D(64, (3,3), activation='relu'),                     # 3×3×64

    Flatten(),           # Flatten to 576-dim vector
    Dense(64, activation='relu'),     # Fully connected layer
    Dense(10, activation='softmax')   # Output: 10 class probabilities
])

model.compile(
    optimizer='adam',
    loss='sparse_categorical_crossentropy',
    metrics=['accuracy']
)
project_code_fnl.py · Data + Training
# Step 2: Load and preprocess Fashion MNIST
from tensorflow.keras.datasets import fashion_mnist

(x_train, y_train), (x_test, y_test) = fashion_mnist.load_data()

# Normalize pixel values from [0, 255] → [0.0, 1.0]
x_train = x_train / 255.0
x_test  = x_test  / 255.0

# Reshape: add channel dimension for CNN input
x_train = x_train.reshape(-1, 28, 28, 1)   # (60000, 28, 28, 1)
x_test  = x_test.reshape(-1, 28, 28, 1)    # (10000, 28, 28, 1)


# Step 4: Train the model
history = model.fit(
    x_train, y_train,
    epochs=5,
    batch_size=64,
    validation_split=0.1,    # 10% used for validation each epoch
    verbose=1
)

# Epoch 1/5 – loss: 0.3521, acc: 87.2%, val_acc: 88.0%
# Epoch 5/5 – loss: 0.1882, acc: 93.4%, val_acc: 91.3%

# Step 5: Evaluate on test set
